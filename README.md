# 周易 · 象数玄机

一个**单文件、零依赖、完全离线**的中国传统术数互动网页。打开 `yijing.html` 即可使用，不需要服务器、不需要联网、不加载任何外部资源（字体、图片、脚本、样式全部内联）。

## ✨ 特点

- **单文件**：全部 HTML / CSS / JavaScript 内联在一个 `yijing.html` 中（约 400 KB），拷贝到任何地方双击就能跑。
- **零依赖**：没有 CDN、没有 npm 包、没有构建步骤。
- **完全离线**：断网可用，适合放进 U 盘、随身上网课、或内网部署。
- **宣纸米黄 · 浅色主题**：护眼配色，中文竖排韵味排版。
- **响应式**：手机、平板、桌面均可阅读。

## 🧮 技术说明

- **农历换算**：采用标准 `lunarInfo` 压缩表（1900–2100 年，共 201 条十六进制记录），逐月推进，正确处理闰月与大小月。已对 2020–2030 年春节、中秋、闰月做回归验证。
- **随机数**：摇卦、求签等使用带种子的确定性伪随机（xorshift / mulberry32），同一天同一问题结果稳定可复现。
- **无外部请求**：页面运行期间不发起任何网络请求。
